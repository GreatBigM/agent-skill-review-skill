# 闸门对抗测试配方（新加的检查脚本）

## 何时用

作者把某条规则从「人记」改成「机器判」——新增 lint / 审计 / 脱敏 / pre-commit / pre-push 脚本时。
**默认假设是它不覆盖它立项要防的那一类**，直到你用那个病例的原文把它压住为止。作者自带的
`--self-test` 不能作为证据：样本是他照自己的实现写的，绿只说明「实现与样本一致」。

## 最小复现（把候选文本喂进脚本）

```python
import subprocess, tempfile, os
AUDIT = "<repo>/scripts/<gate>.py"

def run(text, name="SCHEMA.md"):
    d = tempfile.mkdtemp()
    open(os.path.join(d, name), "w", encoding="utf-8").write(text)
    r = subprocess.run(["python3", AUDIT, d], capture_output=True, text=True)
    return r.returncode, r.stdout.strip()[:160]   # 1 = 拦住，0 = 放行
```

每个样本都配一组**对照**（同一形态去掉嫌疑成分 ⇒ 应当被拦住），否则「放行」无法归因：

| 样本 | 期望 |
|------|------|
| 立项病例**原文**（含那个「骗过人眼」的成分） | 拦住（放行 = P0） |
| 同形态、去掉该成分 | 拦住（证明闸门本身能动） |
| 单句裸数字（无日期无口径） | 拦住 |
| 带口径 + 日期 | 放行 |

## 十类洞：判据与修法

### 洞一 · 判定窗口太宽（「日期张冠李戴」的漏口）

若判定是「本行 / 上一行出现日期或口径字样即算合规」，那么**同一行任何位置**有个日期
就把整行数字全免检 —— 而段落定稿日 / 版本日恰好常出现在同一行。

- 判据：把「数字 + 同行别处的旧日期」当样本 → 放行即是洞。
- 修法：**别只调窗口**——「收窄到同句 / 同括号」仍能被「错标记恰好落在同一句」击破，扩窗缩窗都是调参。
  要**语法化**：要求被判定对象自带**特定格式的声明**（如 `口径：…（YYYY-MM-DD）`），声明只对它**所属的语法单位**生效。
  判据由「附近像不像」变成「有没有那一行」，才可穷举、可回归、不依赖人工兜底。

### 洞二 · 白名单按行豁免

`if any(tok in line for tok in ALLOW): continue` 会让一行里**所有**数字一起免检，
而白名单里常混进 `至少 / ≥ / ≤ / 三种 / 两次` 这类高频词（这些词几乎每屏都出现）。

- 判据：构造「真裸数字 + 行内塞一个白名单词」→ 放行即是洞；再统计白名单词在文档里的行数，约等于被打开的口子。
- 修法：白名单**按匹配项**豁免（只豁免紧邻该词的那个数），结构性计数写成字面量规则（如 `11 项断言`、`八段`）。

### 洞三 · 词表 / 单位覆盖不全

正则量词表（`%|张|条|行|处|跳|个|次|位`）以外的一切数字都看不见：`对`、`卡`、`倍`、`×`、`万`
常见于这类文档，漏掉即「该量词的数字从未被审过」。

- 判据：`grep -oE "[0-9]+ ?(对|卡|倍|×)" <doc>` 数一遍实际分布，再拿一条喂进脚本。
- 修法：补齐量词表；顺带确认 `SCAN` 的**文件覆盖面**（只扫主文档会漏 references/、templates/）。

### 洞四 · 声明的作用域粒度（「块级绑定」仍太粗）

把声明的作用域定成**空白行分隔的段落**，等于一条声明给整块背书——实测一条声明能覆盖十几个数字；
反过来把作用域收成「同行」，写在下一行的合法声明又失效。两种都错。

- 正确单位 = **Markdown 语法单位**，按缩进 / 引用符判归属：
  · 列表项子树 = 该项本级 + 其后所有更深缩进的行；
  · 连续 `>` 行 = 整个引用块；
  · 无空行的续行 / 懒续行（lazy continuation）与上一行同段 ⇒ 同一单位；
  · **空行切断归属**（跨空行的独立段落不认，否则段落级连坐就回来了）；
  · **遇到同级兄弟项必须停止扫描**——「跳过同级但继续往后扫」会把后继兄弟项的**子项**吃进作用域 ⇒ 假豁免。
- 判据（两个方向都要造）：① 声明在某项、数字在**后一兄弟项的子项**里 → 必须拦住；② 数字在**同项子项**里 → 必须放行。
  只测一个方向会把粒度问题整个漏掉。
- 「什么算一条声明」同样要有边界：只要行内出现过关键词就算 ⇒ 任何**提到**该词的句子都能给数字免检
  （「此前口径写作…」「工具侧口径」这类过去措辞 / 术语解释就是典型）。要求该词**被边界引导**（行首 / 括号 / 句读 / 加粗），
  并同时留两条回归样本：「提到 ≠ 声明」必须拦住、**行内合法声明必须放行**（正向控制）——
  只加前者会把修洞修成假阳性，把合规写法一起打掉。

### 洞五 · 描述同步闸门（断言文本 + 语义核指纹）怎么审

作者用机器保证「文档描述不落后于实现」时（声明单一真相源 + 断言该句逐字出现在文档 + 语义核指纹 + 重签命令），
别只看它当前 rc=0，要验**它的防护范围**：

1. **变异矩阵**：在它宣称的范围内**和**范围外各改一处语义。范围内改 ⇒ 必须拒；
   范围外改（解析/扫描**主函数**、**扫描文件清单**）若仍放行 ⇒ 这是无声旁路（等于「判据没变、判定被废」），报 P0/P1。
2. **读它自己的边界声明**：指纹只能证明「实现动过且已显式重签」，**不能**证明「描述写对了」；
   逐字断言只能证明「几处文字互相一致」，**不能**证明「描述 = 实现」。作者把这条写进 docstring 是加分；
   若宣称超出这个范围，按「宣称不实」报。
3. **CHANGELOG 在不在覆盖内**：这类闸门常只断言主文档（SKILL/README），于是「行为变更必须写版本说明」
   这条要求本身仍无机器落点——实测连续几轮「改了判据忘了写说明」。要求补上行为变更条目，
   并让作者显式声明 CHANGELOG 是否纳入断言（不纳入就得靠人，属取舍）。

### 洞六 · 变异测试自身必须先自证落地

报告「闸门无效」之前，先证明你的变异**真的改到了目标**：

```python
assert src.count(目标串) == 1     # 不满足 ⇒ 搜索串与源码不符，变异没落地
```

代价实例：搜索串漏掉一段可选组（`(?:…)?`）、或把变异写成等价空操作 ⇒ 得到「闸门没拦住」的**假红灯**。
两条加固（都实测踩过）：

- **短串是长串的子串**会让 `count` 虚高：单位表 `张|…|度` 是 `张|…|度|字节…` 的子串 ⇒ `count == 2`。
  锚点串要带**上下文**（连上前后的 `r"…"`、分隔符、行首缩进），别用裸的词表 / 片段当搜索串。
- **链式 replace 要逐条断言**：一次没落地的替换会产出「洞仍在」的**假绿**——你会以为修法无效而放弃，
  实际只是补丁里有一句没进去。每步替换后各加一个 assert，最后统一看结果。

同理，改完闸门后**回灌立项病例**才是「修好了」的证据，跑通新加的样本不算。

### 洞七 · 判据换向（「必须标注」→「某类内容不得出现」）

判据换了方向，**洞一~洞四的孔径全部失效**——它们治的是「声明的作用域」，新判据里根本没有声明。
这一类判据天然写成**全称句**（"X 类文档不得含 Y 类内容"），而实现总比句子窄，**差异就是漏口**。按三个维度重开：

| 维度 | 探针 | 命中即 |
|------|------|--------|
| 扫描面 | 列出 `SCAN` 数组，再列出**随包分发**的全部文件（templates/ 等）与**最典型的对外文档**（CHANGELOG） | 未扫描的对外件里躺着同类样本 ⇒ P1，让作者二选一（纳入 / 在判据句写明豁免） |
| 样本形态 | 每个「样本长什么样」各喂一条：带单位 / 占比 / 倍数 / `N/M` / 区间 / 箭头（`190→191`）/ 中文数字 / 裸数+名词；**数值怎么写也是形态**：整数 / **小数**（`1.6MB` `0.5s` `2.5 秒`）/ 全角数字 / 全角空格 / 句首与列表符开头 | 放行 ⇒ 该形态从未被审过（**不带单位的实例最常漏**，因为正则靠单位认样本；**小数最常漏**，因为多分支正则里往往只有一支写了 `(?:\.\d+)?`） |
| 叙述块 | 把「为什么改 / 历史沿革」整段喂进去 | 放行 ⇒ 换向时作者把被禁的旧实例留在了这类段里——它长得像历史、又缺单位，双重隐身 |

另两条必查：

- **闸门自带的「不算」清单逐条判性质**：识别豁免（"这不是计数"）可以留；**语法豁免**（"反引号 / 代码围栏内不算"）是**零成本旁路**——把样本包起来就过关。报 P1，要求至少对反引号内的中文计数单位继续扫，并补两条自检：「反引号内样本必须拦」「反引号内标识符必须放行」。
- **豁免卫生：这条豁免是不是 live**？把**全扫描面**在该版本的非围栏行 grep 一遍：唯一使用点若落在被跳过区域
  （代码围栏内），它从头到尾没生效过 = 死代码，退役零成本（判决表少一条、判据少一个口子）。作者说「这条豁免不生效所以删掉」时，
  用同样的 grep 自己复现，别只信那句话；反过来，作者声称某条豁免在用也要照样验。
- **白名单的「词表内容」取舍**：真上界（`≥ ≤ < > 至少 最多 最少 至多`）算模型常量；`约 / 超过` 是**被禁对象的糊化形态**——留在白名单里 = 闸门自己给 Goodhart 开门（与 SKILL.md B-3 第 3 条「合规走成模糊量词」是同一个洞的两面）。要求删除，或在判据句里明写「约 N 也是样本」。
- **扫描面按「立项理由」判，不按文件清单判**：把某个「随包分发」的目录纳入后，要用**同一条理由**把其余目录过一遍
  ——实测过「templates 纳入了、references/ 仍按旧枚举排除」，两边处置不一致本身就是下一轮的洞。
  新增候选文件时**先把它加进扫描面跑一遍真库**：若报出的是平台 / 配置常量（`8 次` / `60s`），说明豁免表把
  「外部平台常量」实现得太窄（只有字面 `次/时`）——这是取舍（改写或显式声明豁免），别记成闸门失效。
- **已知盲区写进判据 = 加分**：作者把盲区（代码围栏不扫 / 中文数字抓不到）连同**代价**与「约束交回规则」写进判据，
  比假装覆盖强；评审接受边界，但要求每条边界配一条**正向控制样本**，别让「已知盲区」变成默认豁免。

### 洞八 · 负向断言的字符类边界（`\w` 含汉字 ⇒ 汉字紧贴数字即旁路）

用 `(?<!\w)` 排除「长数字的尾巴」是常规写法，但 Python 3 的 str 模式下 **`\w` 包含汉字**
（`re.match(r'\w','共')` → True）：数字紧贴一个汉字（`全库共190 张卡`）时断言命中、整个匹配被跳过。
用户视角是「同一句话，加不加空格决定报不报」，而中文里 `共/有/达 N 张` 是极自然写法 ⇒ 与反引号旁路同族的**零成本旁路**。

- 判据：同句两写法对压 —— `全库 190 卡`（拦）vs `全库共190 卡`（放行即洞）；再试 `该线61 张卡`、`规模190 卡`。
- 修法：负向断言收成**显式字符类**，只排数字尾巴与拉丁标识符：`(?<![\dA-Za-z_.−])`（保留 U+2212 减号）。
  改完**三查**：① 自带 `--self-test` 仍全绿 ② 真库仍 rc=0（收紧边界不得在既有正文上误报）
  ③ 正向控制仍放行（版本号 `v2.10.0` / 线号 `310 线` / 公式 `n−1 张` / 模型常量 `11 项`）。
- 交付形态：报告里直接给这一处替换 + 三条自检（两种汉字紧贴写法各一条正样本 + 一条正向控制），并注明已实测哪几项。

### 洞九 · 闸门内部的第二份真相源（表 / 枚举）——误报与漏报两侧同时中招

一台闸门里极少只有一份「什么算样本」的定义。常见第二处：主单位表 vs **判别器里另抄的小表**、
`SCAN` 数组 vs 判据句里的扫描面枚举、docstring 的 `CURRENT:` vs 「判定」段。**第二份总是滞后**，代价分两侧：

| 侧 | 形态 | 探针 |
|----|------|------|
| 误报（先发作） | 判别器只认主表的**子集** ⇒ 主表已收、小表未收的单位（时长 / 体积）出现在合法区间 / 限定式里就被打红 | 同一构造按单位**成组**对压：`1 至 3 个` / `1 至 3 分钟` / `1–3 秒` / `1–3 MB` / `1 至 3 字节` 全部应放行 |
| 漏报（后发作） | 主表自己缺**同一维度的一半**（收了 `ms/s`、`分钟/小时`，没收中文 `秒/毫秒/天`） | 按时长 / 体积 / 计数三个维度成组列，逐组核；别逐词零敲 |

- **误报比漏报毒**：漏报只是少一道兜底（判据本就声明「约束交回规则本身」）；误报会逼文档把真数字改成
  模糊措辞，改完闸门再也看不见它（Goodhart 反向）——与 B-3「合规走成删数字」是同一个病的两面，报 P1 不报 P2。
- **修法 = 表只写一份**：单位表提成模块级常量，主正则与判别器共用（判别器再补 ASCII 单位组），
  而**不是**把缺的词补进小表——补词只治今天这一例，下次加单位照漂。枚举同理：改成「枚举见上方 X，此处不重复」。
- **补覆盖 / 修误报选判别式，不选豁免式**（SKILL.md B-4 第 15 条）：新增算子并进已有的同形判别器，
  按「后随是不是计数单位」区分常量与样本 —— 一次修掉误报且多抓回一类；豁免式（放行「某词 / 某符号后面的数字」）
  只治误报，会把**裸变体**（无单位 / 无标记那支）一起放过。评审自己给的补丁也要过这一关：先自证落地，再用裸变体回压。
- **回归三查**（每次改判据都重跑）：`--self-test` 全绿 / 真库 rc=0（收紧不得在既有正文上误报）/ 正向控制
  （版本号、线号、公式、模型常量）仍放行；新类别样本按**缺陷类别**加进自检，各配一条正向控制。

### 洞十 · 豁免子句在没预期到的角色上命中（列表符吃掉了区间连字符）

给区间设的豁免常写成「窗口里出现过连字符 ⇒ 这个数是常量」（`[-–]\s*$`）。但 `-` 在中文技术文档里
至少有三种角色：区间连字符（`1-3 个`）、Markdown **列表符**（`- xxx`）、日期分隔符（`2026-10-13`）。
豁免为第一种角色而设，后两种就白白享用它 —— 最自然的一种是**列表项恰好以数字开头**：

| 样本 | 期望 | 实测（同一台闸门） |
|------|------|--------------------|
| `- 全库 190 卡` | 拦住 | 拦住（数字前还有别的字，窗口不以连字符收尾） |
| `- 190 张卡` | 拦住 | **放行**（pre 窗口恰好只剩 `- `） |
| `- 61 张卡同属这条线` | 拦住 | **放行** |
| `* 190 张卡` / `1. 190 张卡` | 拦住 | 拦住（差别只在那个字符） |

- 判据：同一句换四种前缀对压（`- ` / `* `·`1. ` / 无前缀 / 句首）——差别只在符号即豁免泄漏。
- 修法：豁免**绑到前置上下文**，别写成「窗口里出现过某符号」——连字符必须**紧随数字**：`|(?<=\d)[-–]\s*$`。
  改完照旧三查：自检全绿 / 真库 rc=0 / 正向控制（`1-3 个`、`1 至 3 个`、`1–3 MB`）仍放行。
- 通式：**凡豁免都再问一句「它还可能出现在什么角色里」**。本类与「白名单按行豁免」（洞二）、
  「豁免式只治误报」（洞九）是同一个病——豁免按**符号 / 词**匹配，而符号与词是跨语义复用的。

## 严重度定档：这个洞是「潜伏」还是「已在漏」

洞的大小不靠感觉定档。把**修法先落成变体脚本**（补上该堵的规则），拿它扫真库：

- 变体 **rc=0 / 无输出** ⇒ **潜伏**：当下没有样本躲在这条路上。严重度按同族既有判准定，但仍要修
  ——零成本 + 自然写法 = 与已封的旁路同档；作者要拿它当「已知边界」接受，就得在判据里写明并配**正向控制样本**。
- 变体**报出内容** ⇒ **已在漏**：那几行就是实打实漏掉的样本，直接升档，并把内容一起报给作者。

好处是报告里能写一个**可核实的判定**（"用更严的变体扫真库 rc=0，属潜伏"），而不是「我担心它会漏」。

另：**历届病例全过 ≠ 封版**——换一个没试过的写法角度（列表符开头 / 小数 / 全角 / 句首）往往立刻又打出洞，
而重跑上一轮那批样本只会全绿。每轮复审换角度，别把「历史病例复现通过」当收尾依据。

## 复算作者的数字主张（同口径复用它的检查器）

换向 / 瘦身类提交的立论常是一串「原值 X 实为 Y」。复算时**不要另写一套判定**——口径不同会把口径差异
报成数据错（连错好几轮的坑）。直接 import 同仓那个检查器，用它自己的分类函数算：

```python
import importlib.util, os
spec = importlib.util.spec_from_file_location("qc", "<repo>/scripts/<checker>.py")
qc = importlib.util.module_from_spec(spec); spec.loader.exec_module(qc)
root = os.path.expanduser("~/<knowledge-root>")
cards = [os.path.join(root, p) for p in qc.card_files(root)]   # 辅助函数常返回相对路径 ⇒ 必须拼 root
```

- 先落一条**已知能对上的**量（总节点数 / 断言条数）确认口径通了，再去复算争议值。
- 复算值与作者的值差 1~2、且作者自己注明"算的过程里又变了一次" ⇒ 这是「实例数字必然腐化」的现场证据，可用来支持"样本出库"的立论，**不要当数据错报**。
- 同一事件的值在两个发布件里不同（CHANGELOG 说 170、卡说 169）才要报：发布件只留结论，明细归活卡。

## 收尾（四条都要）

1. 确认闸门**真的 armed**：`git config core.hooksPath` 有值 / 已接 CI —— 否则脚本再对也不跑。
2. 把你试出的样本**交给作者加进 `--self-test`**：自检全绿而闸门漏检，就是「看起来有门」。
3. 报告里给出**最小复现**（样本 + 退出码）与**变异落点证据**（`src.count(目标串) == 1`），不要只说「闸门无效」。
4. 文档里的**可执行承诺**（"N 项断言""一行答出当前规模"这类）实跑一次——跑得出，承诺才成立；跑不出就是新的 P1。
5. 作者提出「不建同步断言，改把判据句副本从 N 份降到 1 份」时**接受**：副本越多越会漂（实测同一轮内 4 份副本里
   就有 1 份「本文件是模型与判据」指代错位，粘进了操作手册），削副本比再养一个「守着 N 份副本」的闸门更治本。
   反之，若作者用「判据已收成一句话」推出「同步义务不存在」而副本仍在多处，按未收住报。
